# 小米电视适配说明

实机：小米电视 S55 / MiTV-MFTR0，Android 11（API 30）。本仓库保留了该机型上验证过的适配代码；厂商更新、其他电视型号及安卓版本可能采用不同的默认桌面和统计机制。

## HOME 与开机启动

默认 applicationId 为 `com.bytv.launcher`，源码命名空间仍为 `com.gathin.tvhome`。该包名源自小米实机 HOME 接管适配。原厂桌面包为 `com.mitv.tvhome`，但仓库的通用安装脚本不会禁用它。先确认新桌面可正常启动并保留 ADB 回退方式，再按实际设备处理默认桌面。

开机启动通过系统启动计数和小米电源会话变化判断，处理部分小米电视“关机”实际上进入 STR 的情况。列表仅显示用户安装且可启动的应用。辅助服务启用、后台启动策略和厂商权限会影响结果。

## 按 APP 网速

统计窗口在前台时约每两秒获取一次新快照，读取各 UID 的未打标网络计数，用字节差值和实际采样时间计算 B/s。无线和有线流量均由系统统计。共享 UID 只能合并显示。

Android 11 常规 TrafficStats 无法读取其他应用；本实现使用 Android 11 的 INetworkStatsService 会话刷新，再通过系统诊断接口读取 UID 统计。因此需要：

```text
adb shell pm grant com.bytv.launcher android.permission.DUMP
adb shell appops set com.bytv.launcher GET_USAGE_STATS allow
```

该功能当前仅支持 API 30，其他系统版本不会尝试猜测接口。没有安装 root 辅助程序，没有常驻采样守护进程，也不上传网络明细。

## 悬浮窗

时间使用 HH:mm:ss，背景半透明，显示网络上传和下载速率。桌面和 HDMI/AV 等物理输入源隐藏，普通 APP 中显示。需要 SYSTEM_ALERT_WINDOW；前台判断结合使用情况统计、辅助服务和桌面生命周期。辅助服务恢复需要 WRITE_SECURE_SETTINGS。

## 天气

天气设置支持公网 IP 自动定位和手动搜索城市/区县。新安装默认自动定位；旧版赣州·南康缓存会迁移成手动位置，保留用户原有选择。自动定位使用 ipwho.is（失败时尝试 ipapi.co），随后通过小米接口解析城市；若自动定位失败且已有自动位置缓存，会继续使用该缓存城市。VPN 和网络出口可能影响结果。

城市搜索、反向定位和天气数据来自小米接口，不要求用户另行提供 API key。接口可用性和覆盖范围依赖服务方，海外地点需自行验证。

## 壁纸

图片存放在应用专属外部目录的 wallpapers 子目录。安装包内置实机当前使用的 20 张壁纸原图。每个文件名只准备一次，已有同名文件不覆盖，用户删除后不自动补回；首次升级不会重新放回此前未被选入这 20 张集合的图片。局域网管理页由设置 Activity 启动，访问地址含随机会话路径；关闭设置、刷新二维码或应用进程结束后旧地址不可用。页面删除会直接删除壁纸文件，无回收站、重复备份或缩略图缓存。
